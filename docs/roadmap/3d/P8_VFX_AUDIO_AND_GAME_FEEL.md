# P8 - VFX, AUDIO & GAME FEEL

Modelo: GPT-5.6 Sol
Esforço: HIGH

Escalonar para GPT-6 Astra somente se shaders, render pipeline ou problemas de performance exigirem investigação complexa.

## Objetivo
Adicionar feedback suficiente para ações parecerem responsivas e satisfatórias.

## Escopo
- hit feedback;
- particles;
- screen shake moderado;
- flashes;
- trails;
- reward burst;
- portal/gate effects;
- UI motion;
- SFX;
- ambience;
- music hooks;
- mute/volume;
- reduced motion.

## Critérios
- nenhum efeito compromete leitura;
- sem excesso de camera shake;
- efeitos respeitam reduced motion;
- áudio não inicia de forma incompatível com políticas do browser.
